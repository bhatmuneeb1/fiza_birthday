# For Fiza ✦

A small birthday universe for Fiza, from Muneeb. It unlocks automatically at **12:00 AM IST on September 5, 2026**.

To temporarily bypass the countdown, change `ALWAYS_UNLOCKED` to `true` at the top of `script.js`.

## Preview it before midnight

Open `index.html?preview=1` through a local web server. For example:

```bash
python3 -m http.server 8000
```

Then visit:

- Your private preview: `http://localhost:8000/?preview=1`
- The real, midnight-locked version: `http://localhost:8000/`

## Share it

This is a static site, so it can be deployed free on Netlify, Vercel, Cloudflare Pages, or GitHub Pages. Upload the whole folder and share the generated link without `?preview=1`.

No photos, accounts, APIs, or paid dependencies are required.

The included `assets/fiza-birthday-preview.png` gives the shared link a custom WhatsApp/iMessage/social preview. Its metadata is configured for `https://bhatmuneeb1.github.io/fiza-birthday/`.
